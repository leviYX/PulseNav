# PulseGeo Web 工作台

按用户已确认的 React + TypeScript + Vite / MapLibre 方案实现。Go 同源提供嵌入式前端，保留所有 API 的行为，模型密钥不进入浏览器。

三栏工作台：任务对话、可交互地图、POI 与执行记录。默认 WGS84 上海演示区域，明确合成数据。地图点击设中心、半径调节、围栏逐点绘制（完成时闭环），支持拖动缩放及结果定位。移动端纵向布局。底图使用 OSM 公共瓦片及署名（仅开发演示），可关闭并使用坐标网格；WebGL 不可用时明确降级为可点击的 SVG 坐标示意图，不伪装道路地图。

确定性查询不依赖模型。聊天通过独立请求调用 Agent，发送时可选附带明确的地图上下文；Agent 禁用时解释配置原因，不模拟回答。返回的 search_poi 结果驱动地图及列表。记录请求参数、结果、耗时、错误与取消。执行时保留上次结果并标注状态，失败不显示为新结果；可取消网络请求，避免旧响应覆盖新状态。

不新增多会话持久化、模型配置页面或身份认证。导出查询结果为 GeoJSON。键盘可操作表单、绘图完成与取消；消息、POI 名称和工具输出用 React 文本渲染。

验收：前端参数/闭环/距离范围/取消逻辑测试、组件查询及错误测试；Go 静态资源与未知 API 404 测试；前端生产构建与 Go race/vet/build；实际浏览器检查桌面和移动布局、查询、围栏与聊天禁用状态。
